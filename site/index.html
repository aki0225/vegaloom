03 / INSTALL

安装

安装 Agent extra，然后为目标仓库生成 Codex adapter。主会话里运行 $vega-agent。

Vega 不执行 commit、push、PR 或 release。验证失败时，Finish 不会返回 ready_to_commit。

当前自动 Worker 使用 Codex CLI；Claude Code 主会话通过 assist 流程接入。

PowerShell 
git clone https://github.com/aki0225/vegaloom.git
cd vegaloom
python -m pip install -e ".[agent]"
vega adapters init codex --repo <target-repo>
Codex 主会话入口 $vega-agent
