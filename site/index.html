Agent 最后为什么还要 Reviewer？

因为测试全绿也可能漏掉行为回归。下面保留三份历史脱敏证据， 用真实 Diff、验证与 Reviewer 结论说明 Vega 的最终判断链。

04 / START

把 Vega 装进你的仓库。

初始化后，在新的 Codex 主会话中调用 $vega-agent。 主会话负责调查和展示 Plan，Vega 负责校验批准状态、受控执行、恢复和可信 Finish。

  • 不自动 commit、push、PR 或 release
  • 验证失败不能被 Reviewer approve 覆盖
  • 会话隔离与只读视图不等于 OS 沙箱
  • 当前只支持一个未完成 Work Item 和一个 Writer
PowerShell 
git clone https://github.com/aki0225/vegaloom.git
cd vegaloom

.\.venv\Scripts\Activate.ps1
