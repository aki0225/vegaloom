# Vega v0.5.0 日常入口 Smoke

日期：2026-09-04

## 验证目标

本轮只验证 v0.5.0 新增的日常使用面是否复用既有 ChangeRun 成功语义：

- `vega change` 能否完成 Planning、批准、Worker、Candidate、Verification、Risk、
  Reviewer 和 Finish；
- bounded 模式的低风险任务是否无需人工推进；
- human 模式是否能在当前终端完成一次 Plan 批准；
- Reviewer 明确超时时，是否只在严格前提成立时自动恢复一次；
- 用户原工作区是否保持不变。

真实 Provider 使用独立临时 Git 仓库。任务只允许修改 `calculator.py`，测试文件和
`.vega.yaml` 均不在允许写入范围。

## Case A：Codex bounded

```powershell
Set-Location "<fixture-repo>"
vega change "修复 calculator.py 中 add 的实现" `
  --provider codex `
  --approval bounded `
  --timeout 600
```

- Provider：Codex CLI `0.149.1`
- 源仓库基线：`478a700e2365a3e3bb2164f904a7bc121359b4f8`
- Accepted Candidate：`a3e3e36f428342763a219b814450fd4a4413511e`
- Diff：`calculator.py`，1 行增加、1 行删除
- Verification：
  `python -m pytest -q -p no:cacheprovider tests/test_calculator.py`
- Verification 结果：退出码 0，`1 passed`，Vega 记录耗时约 2.48 秒
- Scope Gate：前置、验证后和 Review 前均为 `success`
- Risk Gate：`success`，低风险
- 独立 Reviewer：`approve`，覆盖实际变更文件，无 finding
- Artifact integrity：`valid`
- Evidence freshness：`fresh`
- Finish：`completed / ready_to_commit`
- `observed_operator_touch`：0
- `observed_authority_touch`：0
- `reported_manual_investigation`：0

源仓库分支没有产生业务文件修改；Candidate 只存在于 Vega 管理的隔离 Worktree 和本地任务分支。

## Case C：Reviewer timeout 契约夹具

Reviewer timeout 没有用真实 Provider 人为制造。本项使用自动化契约测试：

```powershell
python -m pytest -q `
  tests/supervisor/test_agent_reviewer_timeout_retry.py
```

夹具固定证明：

- Coding Worker 只运行一次；
- 第一次 Core Work Item Reviewer 返回明确 `timed_out`；
- Vega 记录一次 `verification_retry_committed`；
- 复用同一 Candidate，完整重跑 Verification、Risk 和 Reviewer；
- 第二次使用新的独立 Reviewer role；
- 第二次成功时进入 `completed / ready_to_commit`；
- 同一 Candidate 第二次超时映射为 `review.retry_exhausted`；
- `error`、`stopped`、终止未确认和最终集成 Reviewer 均不进入自动恢复。

这是一项确定性故障注入，不冒充真实 Provider timeout。

## 证据边界

- 公开记录不包含 Provider Session/Thread ID、模型正文、Token、进程号、绝对本机路径或原始日志。
- 本文件是脱敏运行摘要；临时仓库和原始 Artifact 未公开，所列 SHA 只绑定本次本地运行。
- 本轮真实 smoke 没有主动制造 Provider 命令审批请求；当前终端提示、pending 关闭和非交互
  fail-closed 由 `test_agent_cli_interaction.py` 与 `test_agent_change_driver.py` 覆盖。
- Candidate SHA 是本地隔离 Git 快照的身份，不代表已经 push、merge 或发布。
- `ready_to_commit` 只表示现有证据允许进入人工提交前检查，不证明生产环境安全。
