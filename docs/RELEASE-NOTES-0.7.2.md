安装前请确认对应资产实际存在，本页不代表已发布或已完成下载验收。

## 日常使用改善

- 已编译但尚未批准的任务可以正常取消；取消后提示重新发起并确认计划，不误导继续执行。
- 持久 Codex Worker 与短会话保持单 Writer 边界。项目强制子代理流程不自动兼容，
  遇到冲突需人工决定项目工作流，不由 Worker 擅自改规则。
- 验证摘要优先呈现失败，保留有界首尾和真实日志位置；风险待人工判断时，
  同时提示可信的验证失败。人工确认风险不等于验证通过。
- `vega change --json --progress` 可在 stderr 查看阶段、已有事件和耗时，
  stdout 仍为单个最终 JSON，不读取 stdin、不自动批准。终端文本规范化后再脱敏；
  不加 `--progress` 时保持原 JSON 静默进度行为。
- 环境准备失败时显示命令序号、终态、退出码及实际记录位置，帮助先核对环境；
  不自动重试、不启动 Worker，也不保证再次 `change` 能重跑。

## 使用边界

仍需项目准备/验证配置、适用规则和关键人工授权；高风险修改需人工检查。
模型及独立 Reviewer 不保证绝对准确，测试通过也不是生产安全证明。
Vega 不自动 push、merge 或 release，不承诺完全无人值守。

此前跨项目试用中，Python 标准工具完成过真实 Worker、验证与独立审查，原项目未采纳；
这不是本版本的新一轮真实重测。Echo 完整门禁未通过、候选不采纳；电商和 Go 环境也未取得
完整成功，不能据此声称自动适配所有 AGENTS 或项目工作流。自然 repair 链路及 Claude
本轮未重新实测，历史失败和未完成事项保持原结论。

发布维护仍需核对最终 PR/main CI、精确提交的干净 wheel/sdist 与独立安装、资产摘要及
公开下载。当前准备阶段不替代这些后续检查。
