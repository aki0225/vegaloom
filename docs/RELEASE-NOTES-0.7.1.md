# Vega v0.7.1 发布说明

源码包版本为 `0.7.1`。发布状态与可下载资产以
[GitHub Release](https://github.com/aki0225/vegaloom/releases/tag/v0.7.1) 为准；
安装前请确认对应资产已提供。本页不代表已完成发布或下载验收。

## 日用修补

- 配置缺失提示明确指向 HEAD 中已提交的 `.vega.yaml`，给出核对、提交配置与
  `vega config check --repo . --change` 的下一步。
- 无任务或多个任务无法唯一选择时，`status/explain --json` 保持结构化错误；
  文本提示帮助用户创建任务或显式指定 `--run`，不猜测最新任务。
- 正常高风险待人工确认时展示代码目录、Candidate、Diff与实际审查/风险报告入口；
  这是人工检查指引，不是自动批准或交付成功。
- 状态查询复用同次投影，避免对明确不适用的补验/重算重复执行昂贵资格检查。
  一台本机样例约从9.5秒降至7秒，仅为小样本观察，不承诺所有项目同等提速。

## 不变的边界

权限、风险、真正执行准入与前后两次 Workspace 检查均未改变。
使用仍需项目准备/验证配置和关键人工授权；模型可能误判，独立审查不保证绝对准确，
高风险任务仍需人工判断。Vega 不自动 push、merge 或 release，不承诺完全无人值守。
总体能力与限制沿用 [v0.7.0 发布摘要](RELEASE-SUMMARY-0.7.0.md)。

## 验证与发布核对

日用修复合并后的 CI 已覆盖 Python 3.11 全量（1816通过、14跳过）、
Python 3.12 Supervisor（620通过）及其余平台职责；这是修复基线的结果，
不是本补丁发布提交、安装包或下载验收的替代。
本地 Windows 旧补验整链曾触及58秒限制，记录保留；对应 Linux CI 用例通过，
不能将其表述为本地超时已通过。

发布维护流程仍需核对最终 PR/main CI、精确提交的干净 wheel/sdist、独立安装、
资产摘要和公开下载。此次不重做长期真实 Provider 验收，也不宣称未自然触发的
repair 流程或 DAILY-03 已完整实测。
