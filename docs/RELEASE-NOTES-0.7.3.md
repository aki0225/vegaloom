# Vega v0.7.3：控制层精简与审查体验改善

源码包版本为 `0.7.3`；发布状态和可下载资产以
[GitHub Release](https://github.com/aki0225/vegaloom/releases/tag/v0.7.3) 为准。
安装前请确认资产实际存在；暂不通过 PyPI 发布。

## 本次变化

- 可信风险返修和审查裁决不再依赖首屏展示或 `FAIL:` 文案，既有批准、证据和验证约束保持。
- 控制器因风险或审查覆盖不足降级时，保留可信的 `change_impacts` 等审查材料；不可信材料仍拒绝。
  状态页区分审查门禁与审查材料，一般下一步回到所属 ChangeRun 的 `status` / `explain`，不凭 Reviewer 的 approve 建议提交。
- 合并验证暂停的重复处理，保留超时、停止、终止未确认以及配置/快照失败的不同原因与写入顺序。
- 简化旧 Plan 的内部投影，公开 CLI 主路径、合同和成功语义不变。

## 安装包边界

公开 `adapters init codex` 的 Skill 安装与路径保护迁到产品模块 `vega.host_skills`。
wheel 不再包含 `vega.experimental` 和历史 Loop YAML；实验执行请使用源码 checkout。
sdist 保留实验源码、相关规则和资源供查阅，但不是完整历史复现包；安装 sdist 得到的仍是产品 wheel。
内部模块不是稳定 Python SDK，使用旧实验导入的脚本需改为在仓库环境运行。

## 验证与限制

已合并重构的主线 CI 通过；本机 Windows 风险返修节点的 58 秒超时及一次 180 秒诊断未完成历史仍保留，
不表示本地耗时问题已经修复。本次不承诺模型准确率、人工审查用时或普适性能提升。

高风险修改仍需人工判断，项目配置和规则仍需适配；Reviewer 材料不能替代确定性验证或人工授权。
本次没有扩大真实 Provider、Claude、自然 repair 或历史跨项目成功的验证范围。
此前 Echo 完整门禁未通过，电商和 Go 环境未取得完整成功；这些边界不因本次重构而改变。
最终发布仍需核对发布提交 CI、干净制品安装及公开下载；本说明不宣称这些步骤已经完成。
